REASONING LAB — PUBLIC WEBSITE PACKAGE

Files:
- index.html      Homepage with links to both versions
- version1.html   Original uploaded website (Version 1.0)
- version2.html   Enhanced uploaded website (Version 2.0)

LOCAL PREVIEW:
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Select Version 1.0 or Version 2.0.

FREE PUBLIC HOSTING WITH GITHUB PAGES:
1. Sign in to GitHub and create a new public repository, e.g. reasoning-lab.
2. Upload index.html, version1.html, and version2.html to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. The public URL will appear in Settings > Pages.

This is a static HTML/CSS/JavaScript website. No server, Python runtime, or database is required.

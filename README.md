# Reasoning Lab — Forward and Backward Chaining

An interactive educational website that explains how rule-based AI systems use facts and IF–THEN rules to derive conclusions.

This project contains **two versions** of the learning website:

- **Version 1.0** — the original beginner-friendly guide with interactive forward chaining, backward chaining, a comparison table, and a short quiz.
- **Version 2.0** — an enhanced version with a step-by-step forward chaining simulator, a backward chaining proof trace, a progress indicator, and a four-question quiz with explanations.

## Live Website

After enabling GitHub Pages, your website will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/reasoning-lab/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.

## Website Files

| File | Description |
|---|---|
| `index.html` | Landing page where visitors choose Version 1.0 or Version 2.0. |
| `version1.html` | Original Reasoning Lab website. |
| `version2.html` | Enhanced Reasoning Lab 2.0 website. |
| `README.md` | Project overview and setup instructions. |

Keep all three HTML files in the **root of the repository**. Do not put them inside a separate folder unless you also update the links in `index.html`.

## Features

### Version 1.0 — Original

- Introduction to facts, rules, and inference in rule-based AI.
- Interactive forward chaining demonstration.
- Interactive backward chaining demonstration.
- Comparison of forward and backward chaining.
- Short knowledge-check quiz.

### Version 2.0 — Enhanced

- Step-by-step forward chaining: apply one matching rule at a time.
- Option to run all forward chaining steps.
- Progress indicator and inference trace.
- Backward chaining proof trace showing goals and sub-goals.
- Expanded quiz with four questions and explanations.
- Responsive layout for desktop and mobile screens.

## Run the Website Locally

No installation, server, database, or programming environment is required.

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a web browser.
4. Choose the version you want to explore.

You can also open `version1.html` or `version2.html` directly.

## Publish for Free with GitHub Pages

1. Sign in to [GitHub](https://github.com/).
2. Create a new repository named `reasoning-lab`.
3. Set the repository visibility to **Public**.
4. Upload `index.html`, `version1.html`, and `version2.html` to the repository root.
5. Commit the uploaded files.
6. Open the repository's **Settings** tab.
7. Select **Pages** from the sidebar.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch `main` and folder `/(root)`.
10. Click **Save** and wait for GitHub Pages to finish publishing.

Your public website URL will be:

`https://YOUR-GITHUB-USERNAME.github.io/reasoning-lab/`

GitHub may take a few minutes to publish the first deployment. The URL will also be shown in the repository's **Settings → Pages** section.

## Educational Note

The examples in the website use simplified facts and rules to demonstrate how forward and backward chaining work. They are learning examples, not real-world forecasts or professional advice.
